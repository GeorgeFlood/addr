# addr

addr started as a project I was genuinely excited about.

The idea was simple: create a clean, easy-to-use address lookup service that could eventually be integrated into websites, apps, and even a Chrome extension. The long-term vision was to provide a lightweight API that other developers could build on top of.

Unfortunately, while building the project, I discovered that the underlying address data API is only free for a limited period. After that, every request comes with a cost.

That changes the economics of the project significantly. If every user action costs money, it becomes much harder to justify offering the service freely or encouraging third-party integrations without passing those costs on.

For now, that has taken a lot of the wind out of my sails.
